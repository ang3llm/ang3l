Plate · Inside

Every word is handed to one expert in each layer.

AM3N is a mixture-of-experts transformer: two layers, each with four attention heads and eight expert networks. For every word a router picks one expert per layer and the other seven are never read, so about 320,000 of its 1,239,424 weights are touched per word.

The experts

Eight voices, one at a time

Each layer's feed-forward part is eight experts of width 256 behind a top-1 router. Only the chosen expert's weights are read, so each word touches 319,744 of the 1,239,424 weights.

The kernel

Eight weights a multiply

Weights are stored one byte each, 32 to a 256-bit word. The kernel takes eight at a time, so one EVM multiply does eight multiply-accumulates at about 6.2 gas each. That is how a whole blessing fits in 29M to 41M gas.

The math

Integers only

No floating point anywhere: every step is integer arithmetic, so every node returns the same words. A Python reference matches the contract bit for bit, in 18 of 18 tests.

Plate · Proof

Each address is sealed to the bytes it holds.

Fifteen contracts hold the weights and one engine runs them. Each weight contract was created through the standard CREATE2 deployer with salt 0, so its address is derived from the hash of the exact bytes it holds. You can check that from this page.

Plate · Questions

Printed on the reverse.

iIs it really on chain?

Yes. The weights are the code of fifteen contracts on Robinhood Chain, and the engine that runs them is verified on Sourcify as an exact match. When you ask, a Robinhood Chain node runs the whole model; this page only sends your words and shows the answer.

iiWhy is it free?

Asking is an eth_call: a read, not a transaction, so nobody pays gas. A whole blessing takes 29M to 41M gas, which fits inside the 50M that Robinhood Chain's public RPC allows for a single read.

iiiDo I need a wallet?

No. To bless a wallet you only paste its address. The contract reads public facts about it in the same call, its balance and whether it is a contract; nothing is signed and nothing leaves any wallet.

ivWhat does it know?

Blessings, in four moods: for the builder, the holder, the night and the friend. It was trained on 80,000 short blessings, hand-written sentences plus a grammar. It does not chat or follow instructions; it is small on purpose, so that every word can be computed on chain.

vWhy does the same name give the same words?

Your words seed the sampler and every step is integer math, so the same input gives the same sentence on every node. A wallet's blessing changes once a day at 00:00 UTC, and today's blessing is the same for everyone until then.

viIs $AM3N an investment?

No. AM3N is an experiment and a free tool, and the $AM3N token carries no promise of value or return. Its creator fees pay for putting the next angels on chain, starting with the second model, which is trained and tested; larger models after that are research. Asking stays free whether you hold it or not. Only buy what you can afford to lose.

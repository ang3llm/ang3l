III · Inside

Eight voices a layer.
One speaks at a time.

The angel is a mixture of experts. Every layer holds eight expert networks and a small router; for every word the router picks one, and the other seven are never read. 1,239,424 weights on chain, about 320,000 of them touched per word.

the experts

Mixture of experts

Two transformer layers, width 128, four attention heads. Each layer's feed-forward part is eight experts of width 256; a top-1 router chooses which one runs.

the kernel

Eight weights per multiply

Weights are int8. The engine lines up eight of them in one 256-bit word and multiplies all eight by the input with a single EVM instruction, about 6 gas per multiply-accumulate.

the math

Integers only

Every step is an integer add, multiply, shift, square root or table lookup, so every node returns the same words, and a Python reference matches the contract bit for bit.

VII · Questions

Asked often.

Is it really on chain?

Yes. The weights are the code of fifteen contracts on Robinhood Chain and the engine that runs them is verified on Sourcify. When you ask, a Robinhood Chain node executes the model; this page only sends the question and shows the answer.

Why is it free?

Asking is an eth_call, a read. Reads don't create transactions, so nobody pays gas. The whole model was designed to fit inside the 50M gas a public RPC allows for one read.

Do I need to connect my wallet?

No. To bless a wallet you only paste its address; the contract reads public data (its balance and whether it is a contract). Nothing is signed and nothing leaves your wallet.

What does it know?

Blessings, in four moods. It was trained on 80,000 short blessings, a mix of hand-written sentences and a grammar. It does not chat or follow instructions; it is small on purpose so that every word is computed on chain.

Why does the same name give the same blessing?

The words you type seed the sampler, and the math is integer only, so the same input gives the same sentence on every node. Wallet blessings change once a day.

What do the creator fees fund?

The next versions of the angel: deploying larger models and keeping every one of them free to ask.
